# Zethos engraved plates

Original art generated for this project, in one shared style: fine-line steel engraving in a single
ink (`#14113a`) on white. Paper tones are cleaned to pure white and files encoded as WebP.
Displayed with `mix-blend-mode: multiply` (`.plate`) so they sit directly on the page.

| Files                                                           | Tool                |
| --------------------------------------------------------------- | ------------------- |
| `panorama`, `valley`, `gates`                                   | Codex CLI           |
| `seal`, `depth`, `speed`, `atomic`, `balance`, `shield`, `open` | Antigravity (`agy`) |
